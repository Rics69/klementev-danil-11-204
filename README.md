## Что сделано

Этот репозиторий содержит краулер на Node.js, который:

- **скачивает минимум 100 текстовых HTML‑страниц** из заранее подготовленного списка `urls.tsx`;
- **сохраняет каждую страницу как есть** (HTML не очищается) в отдельный текстовый файл в папку `dump/`;
- **генерирует `index.txt`**, где для каждого сохранённого файла указан его номер и ссылка на страницу;
- **упаковывает результат в архив** `submission.zip` (внутри: `dump/` и `index.txt`).

## Требования

- **Node.js 18+**

## Установка

```bash
npm install
```

## Запуск краулера

По умолчанию скачивается **минимум 100 страниц** из списка `urls.tsx` (краулер перебирает ссылки, пока не сохранит 100 успешных выкачек):

```bash
npm run crawl
```

Полезные опции:

- **`--target 100`**: сколько страниц нужно успешно сохранить (по умолчанию 100)
- **`--limit 120`**: использовать только первые N ссылок из списка
- **`--limit all`**: использовать все ссылки из списка (по умолчанию)
- **`--concurrency 5`**: параллельность (по умолчанию 5)
- **`--delay 200`**: задержка между запросами в миллисекундах (по умолчанию 200)
- **`--retries 3`**: количество повторов при ошибке (по умолчанию 3)
- **`--outDir dump`**: папка для выкачки (по умолчанию `dump`)
- **`--no-clean`**: не очищать папку перед стартом

Пример:

```bash
npm run crawl -- --target 120 --concurrency 4 --delay 300
```

После выполнения появятся:

- `dump/0001.txt`, `dump/0002.txt`
- `index.txt` в корне проекта (формат строк: `NNNN<TAB>URL`)

## Сборка архива для отправки

```bash
npm run pack
```

Будет создан файл `submission.zip`.
